# Exp-018: Intent Disambiguation Kurikulum vs General Homework Solver

Laporan hasil riset dan evaluasi empiris Task-Oriented Intent Disambiguation pada Tier 2 Semantic Gate FTMM COMPASS.
Memisahkan secara matematis dalam ruang laten semantik kontinu ($d=768$) antara kueri eksplorasi kurikulum/silabus sains FTMM dengan permintaan penyelesaian soal/PR/rumus sains lepas.

## Artefak Evaluasi
- `benchmark_summary.md`: Analisis performa komparatif dan temuan ilmiah.
- `benchmark_metrics.csv`: Data kuantitatif terstruktur per kuadran.
- `benchmark_results.json`: Ringkasan metrik JSON untuk analisis programmatic.
- `benchmark_raw_traces.jsonl`: Jejak audit inferensi 120 kueri uji secara mendetail.
