# Exp-030: Benchmarking Kompleksitas Multi-Hop Retrieval & Ketahanan Kontaminasi Konteks RAG

Repositori eksperimen ini mengevaluasi batas kapabilitas temu balik (Information Retrieval) dan ketahanan model terhadap kontaminasi distraktor kurikulum silang prodi.

## Berkas Artefak Eksperimen
- `benchmark_summary.md`: Laporan naratif dan tabel komparatif per tier.
- `benchmark_metrics.csv`: Matriks data numerik evaluasi formal.
- `benchmark_results.json`: Rekap agregat terstruktur format JSON.
- `benchmark_raw_traces.jsonl`: Jejak mentah 180 evaluasi skenario.
