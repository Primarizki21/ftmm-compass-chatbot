# Exp-032: Evaluasi Komparatif Hypothetical Document Embeddings (HyDE) & Adaptive Query Expansion

Eksperimen ini mengevaluasi metode Hypothetical Document Embeddings (HyDE) dan perutean adaptif (Adaptive Gated HyDE) pada model bahasa kecil lokal (SLM 3B) untuk menjembatani kesenjangan representasi semantik kueri mahasiswa FTMM.

## Berkas Artefak Eksperimen
- `benchmark_summary.md`: Ringkasan naratif, tabel komparasi 4 varian, breakdown per kategori kueri, dan analisis Bab 4 TA.
- `benchmark_metrics.csv`: Matriks data numerik evaluasi formal per varian dan per kategori.
- `benchmark_results.json`: Rekapitulasi metrik terstruktur JSON.
- `benchmark_raw_traces.jsonl`: Rekaman jejak mentah 80 kueri evaluasi.
